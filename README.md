# Lumiere

Lumiere is a Flutter music player based primarily on our Nocturne app, with Lumiere-specific branding and changes by egold070799. Existing copyright and license notices in the source remain applicable.

## Requirements

- A Flutter SDK satisfying the constraint in `pubspec.yaml` (minimum 3.47.7)

## Run on Android

```powershell
flutter pub get
flutter run --flavor github
```

Build an APK with:

```powershell
flutter build apk --flavor github
```
